# webpage-archiver 宣传片 · 调研笔记

## 产品事实与出处

| 事实 | 出处 |
|---|---|
| 将网页归档为 Markdown、PDF、离线 HTML，并下载图片与 CSS/字体依赖 | `/repo/sub-project/ETM/README.md`、`scripts/archive_web.py` |
| 默认产出 `article.md`、`article.pdf`、`index.html`、`assets/`、`source.html`、`metadata.csl.json`、`citation.bib`、`manifest.json`、`verification.json` | `references/workflow.md`、`scripts/archive_web.py` |
| MathJax 公式冻结为 SVG，Markdown 保留 TeX | `SKILL.md` 第 3 节、`scripts/archive_web.py` |
| 离线 HTML 会拦截外部请求并检查 JS 报错、公式报错、图片加载 | `scripts/archive_web.py` 的 Chromium 校验段 |
| Zotero 导入由 agent 通过 MCP 执行，脚本本身不直接访问 Zotero | `SKILL.md` 第 4 节、`references/workflow.md` |
| 仓库自带 3 项测试在本机全部通过（TeX 保留、URL scheme 限制、本地网页离线归档与 PDF 集成） | 2026-11-07 运行 `python -m unittest discover -s tests -v`，3 tests OK |
| 仓库尚未指定开源许可证 | `README.md` 来源与发布说明 |

## 用于画面的真实素材

- 演示文章：Lilian Weng, *LLM Powered Autonomous Agents*，https://lilianweng.github.io/posts/2023-06-23-agent/
- 使用本仓库 `scripts/archive_web.py` 现场归档，截取真实的 `index.html`、`article.pdf`、`article.md`、`assets/`、`verification.json` 与终端输出。
- 不使用模拟的 Star 数、用户数或客户 logo。

## 制作与验收记录

- 配乐：Mixkit *Just Keep Walking*（ID 963，约 129 BPM，2:05），来源 https://assets.mixkit.co/music/963/963.mp3 ，按 Mixkit 免费许可使用。
- 成片：1920×1080、60fps、45.06 秒、24.3 MB、H.264 + AAC；响度 -13.8 LUFS，真峰值 -0.8 dBFS。
- 自动检查：`check_video.py` 0 ERROR；渲染日志无报错；8 个场景抽帧联系表已人工查看。
- 画面中的真实数据：13 张图片、16 处数学、21 页 PDF、0 个外链请求、0 个 JS 报错。
- 未执行 Zotero 写入；网页版和 4K 版本未在本轮制作。

## 事实边界

- 片中不声称“所有网页都能无损转换”；脚本主要处理能直接取得完整 HTML 的文章。
- Zotero 只做一句能力提示，不展示未实际执行的写入结果。
- 音乐来自 Mixkit，免费可商用；交付时保留曲目来源。
- 公开文章截图仅用于展示工具输出，画面标注原文 URL。
