# webpage-archiver 宣传片 · 需求确认

## 产品

- 一句话定位：把网页文章完整归档为 Markdown、PDF 和离线 HTML，需要时再导入 Zotero。
- 目标用户：经常保存长文、论文、技术博客的开发者、研究者和内容工作者。
- 核心卖点（按重要性）：
  1. 正文、图片、图注、表格、公式和参考文献一起保存，不是只存一个链接。
  2. 图片与 CSS/字体本地化，生成断网也能打开的离线 HTML。
  3. 同一份原文同时产出 Markdown、A4 PDF 和可检索的元数据。
  4. 可选通过 Zotero MCP 查重、导入并核验。
- 可证明的数据：仓库自带 3 项测试在本机全部通过；单次归档会生成 9 类交付文件。宣传片不编造用户量、Star 数或性能数字。
- 网址：https://github.com/lyh843/webpage-archiver

## 风格要点

- 配色：米白纸面 `#F7F3E6`、墨色 `#23303B`、马克笔蓝 `#3C7DD9`、印章红 `#D1493C`、荧光黄 `#FFD86A`。
- 字体：标题用站酷庆科黄油体（开源），正文用 Noto Sans CJK SC；标题像马克笔写出来。
- 动效语言：元素像被“贴”上白板；手绘箭头逐段画出；真实截图用胶带固定、轻微旋转；转场像撕下或翻过一张纸。
- 质感：纸纹、便签、胶带、记号笔描边、轻微抖动（boiling line），不做光滑 3D。
- 明确不要的：深色科技风、霓虹、通用 SaaS 渐变卡片、假 UI 数据、夸张的“颠覆/革命”措辞。

## 交付结果

- 成片：`宣传片 1080p.mp4`，1920×1080、60fps、45.06 秒、24.3 MB，H.264 + AAC。
- 封面：`封面.jpg`；工程源码和全部素材在 `工程/`。
- 自动检查：`check_video.py` 通过，渲染日志无报错，响度 -13.8 LUFS，真峰值 -0.8 dBFS。
- Zotero 只做一句能力提示，没有执行任何实际写入。
- 本轮未做网页版和 4K 导出，按确认的 1080p 规格交付。
